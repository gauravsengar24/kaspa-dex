# KaspaSwap — Native Kaspa L1 DEX

Peer-to-peer atomic swap orderbook for KAS ↔ KRC-20 tokens on Kaspa mainnet.

- **Swap**: P2P orderbook for KAS ↔ KRC-20 token swaps
- **Wallet**: View KAS balance + KRC-20 token balances
- **Analytics**: Price feeds, orderbook depth, transaction history

Built with React + Vite + Tailwind CSS v4 + FastAPI (Python).
